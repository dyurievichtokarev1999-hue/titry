### Короткий текст и «/текст» в боте (PR 15, решение Claude 11.11 15:05)

- Текст короче 12 знаков: при признаках опасности — путь рассказа (остановка и помощь). Без признаков — отдельная модельная проверка до любого ответа. «Расскажи чуть подробнее» — только после ответа «безопасно». При неизвестном исходе (сбой, нет ключа, пауза) — текст неизвестного исхода и контакты помощи, без «подробнее». Пока ключа нет, все короткие тексты без признаков получают этот ответ: это ожидаемо.
- Однословные формы самоповреждения («порежусь», «отравлюсь», «удавлюсь», «утоплюсь», «застрелюсь», «вскроюсь», «убьюсь», «выпилюсь», «наглотаюсь», «не жить мне») — urgent. Бытовые совпадения («отравлюсь шавермой», «выпилюсь из чата») остаются строже. Они ждут решения людей: гипербола (РЕШЕНИЕ 7.11).
- Текст на «/», если это не известная команда, идёт путём рассказа. У известной команды с хвостом проверяется хвост.
- Сообщение во время подготовки ролика (КОД-РЕВЬЮ QA 12.11, решение Claude 12.11 11:05): сначала та же проверка, что у короткого текста. Доставка прежнего ролика ждёт этих проверок. urgent — экран остановки, прежний ролик отменяется навсегда. concern — блок помощи, ролик доставляется. Безопасное — «Собираю ролик…». Неизвестный исход — текст неизвестного исхода и контакты.
- Удержание доставки снимается только после применения результата проверки (решение Claude 12.11 15:10). Сбой вспомогательного шага (эхо расшифровки, «Собираю ролик», typing, экран помощи) не снимает удержание. Сбой без результата и «неизвестно» — ролик не отправляется. Расшифровка голоса проверяется до эха. После предела ожидания «Собираю ролик» не отправляется.
- Экран остановки отправляется первым и ни от чего не зависит (решение Claude 12.11 20:00). При urgent эха расшифровки нет, метрики пишутся после. У вызовов Telegram API есть предел ожидания приложения: 10 с, длинный опрос — 45 с, загрузка видео — 120 с.
- Неизвестный исход любого входа во время подготовки (длинное или нераспознанное голосовое, пустая расшифровка, кружок, аудио, видео, стикер, сбой проверки, предел ожидания): ролика нет, человек получает одно сообщение — причина, «Проверка не завершилась, поэтому ролик не отправлю.» и контакты. Формулировки временные, утверждает редактор.
- «Мне уже / теперь не жить» и «мне не жить без <кого/чего>» — urgent по тем же правилам (12.11). «Мне не жить без кофе» — ложное urgent, строже решения 7.11.
- Короткий текст проверяется разово (`gate.probe`), без счётчика неполных ответов и без технической паузы. Иначе два сбоя модели на «Привет» навсегда закрыли бы это слово участнику: в боте нет ручного повтора организатора.
- Ложные срабатывания нового словаря видны на бытовых фразах: «отравлюсь шавермой опять», «утоплюсь в работе», «на этой горке точно убьюсь», «самоубьюсь от скуки», «без кофе не жить мне», «выпилюсь из чата», «вскроюсь на покере». «Мне не жить» — urgent в конце фразы и рядом с «больше / дальше / так / без …» (решение Claude 11.11 16:05). «Мне не жить в/на <место>» и «мне не жить с <человек>» — нет. Они остаются строже и ждут решения людей (РЕШЕНИЕ 7.11). «Сброшусь» не входит в словарь: «сброшусь на подарок» — бытовое. Короткое «сброшусь» уходит на модель.

## Нужны ваши действия

1. **Название и знак.** Проверка по базе ФИПС и доменам — чек-лист в [naming.md](naming.md).
2. **Контакты помощи.** Проверьте номера в `config/help.json` для страны запуска и поставьте `verified: true`. Пока бот показывает только 112.
3. **Ключи.**
   - `ANTHROPIC_API_KEY` — черновики Claude.
   - `YANDEX_API_KEY` и `YANDEX_FOLDER_ID` — голосовые.
   - `TELEGRAM_BOT_TOKEN` — бот, выдаёт @BotFather.

   Без ключей Claude и Яндекса всё работает на заготовке без ИИ и только с текстом.
4. **Доступность Claude API в стране, где будет сервер и юрлицо.** Если API недоступен, слой черновика нужно заменить на другого провайдера. Остальной код от этого не зависит.
5. **Музыка.** Четыре синтезированных эскиза годятся для теста. Для запуска закажите 20–30 треков с полным выкупом прав, включая публикацию в соцсетях.
6. **Пороги успеха теста** — зафиксируйте до старта (`concierge/protocol.md`).

## Почему так

- **Сервер вместо устройства.** Черновик из свободного рассказа всё равно делает облачная модель, поэтому обещание «всё локально» было бы нечестным. Обещаем то, что выполняем: рассказ не хранится, ролик удаляется с сервера сразу после отправки.
- **Telegram вместо стора.** Голосовые — родная привычка аудитории. Ролик 9:16 сразу готов для историй. Первую проверку можно провести без публикации в сторе.
- **Модель по умолчанию — `claude-opus-5-5`.** Меняется переменной `TITRY_MODEL` без правки кода. На черновик уходит около 1–2 тыс. токенов. Точную стоимость эпизода посчитайте на первых реальных рассказах по полю `usage`.
