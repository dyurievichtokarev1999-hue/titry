# Набор для проверки черновиков

`narrative-cases.v1.json` — 15 вымышленных историй от координатора и редактора повествования GPT (7.11.2026). Это сложные случаи: сарказм, горе, пустой день, два чувства, имя без рода, чужая реплика, злость, догадки о других, отрицание и время, вложенная инструкция, самоисправление, сон, надежда, условный план, собственная цитата.

**Что проверяется автоматически сейчас** (`tests/narrative-cases.test.js`, без модели):
- каждая цитата-источник дословно есть в рассказе;
- определение рода по собственным словам рассказчика.

**Что ещё не проверяется:** смысл черновиков модели по спискам `keep` и `avoid`. Для этого нужен прогон с ключом Anthropic: черновик → проверка цитат → разбор людьми или моделью-оценщиком. Результат каждого прогона записывается с коммитом, моделью, настройками и фактическим провайдером. Заготовка без ИИ после ошибки API успехом модели не считается.

Набор не проверяет фильтр безопасности: для него — `tests/safety-idioms.test.js`.
