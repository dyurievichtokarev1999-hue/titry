# Инструкции для агентов — «Титры»

Этот файл читают все агенты, которые работают с кодом: ChatGPT/Codex и Claude. Общение, задачи и решения живут не здесь, а в Google Drive, в папке «Титры — приложение / Обмен с Claude — Титры». До первой задачи прочитайте там:
- «00 Протокол обмена — Титры — читать первым»;
- «00 База — концепция, решения и план до релиза».

## Продукт

Вечером человек рассказывает голосом или текстом, что было сегодня, и получает ролик 9:16 на 24 секунды: титры своего дня с музыкой. В ролике:
- название и жанр;
- «в главной роли — ты»;
- 3–6 строк «роль — значение»;
- саундтрек;
- «Конец сцены»;
- сцена после титров.

Первый канал — Telegram-бот.

## Как устроен код

| Путь | Что |
|---|---|
| `engine/episode.js` | Модель эпизода и все проверки бережности. Чистый модуль, работает в браузере и в Node |
| `engine/draw.js` | Рендерер на Canvas. Предпросмотр и итоговый MP4 рисует один и тот же код |
| `server/render.js` | MP4 через Playwright (Chromium) и ffmpeg |
| `server/draft.js` | Черновик: Claude со структурированным JSON или заготовка без ИИ |
| `server/safety.js`, `config/help.json` | Фильтр опасных тем и экран помощи |
| `server/bot.js`, `server/stt.js` | Telegram-бот и распознавание голоса (Yandex SpeechKit) |
| `server/app.js`, `studio/` | Монтажная для ручного теста |
| `tests/` | `node --test` |

Запуск: `npm install`, `npm test`, `npm run studio`. Переменные окружения — в `.env.example`.

## Правила работы с кодом

1. **Только через pull request** в `main`, с заполненным шаблоном. Прямо в `main` не пишет никто. Сливают люди.
2. **`npm test` должен проходить.** На каждый pull request GitHub запускает тесты автоматически.
3. Новое поведение — с тестом. Ошибка — сначала тест, который её воспроизводит.
4. **Ревью.** Код агентов ChatGPT проверяет Claude: сообщение КОД-РЕВЬЮ со ссылкой на pull request в «01 Входящие для Claude». Код Claude проверяет агент QA.
5. Ветки называйте по автору и задаче: `gpt/qa-deploy-plan`, `claude/real-keys-run`.
6. Ключи, токены и пароли — только в переменных окружения. Никогда не в коде, тестах, коммитах и документах.
7. Не добавляйте зависимости без причины. Сейчас обязательная зависимость одна — `@anthropic-ai/sdk`.
8. Не меняйте шрифты, музыку или знак без подтверждённых прав. Шрифты — OFL 1.1, звуковые эскизы — собственный синтез.

## Правила бережности (не нарушать без РЕШЕНИЯ людей)

- В титрах только то, что человек сказал сам: у каждой строки есть дословная цитата-источник (`source`). Строки без опоры не попадают в ролик.
- Род не угадывается по имени. Он берётся только из слов человека о себе, иначе — именные фразы («Письмо — отправлено»).
- Нет слов «финал» и «конец» без «сцены», навязанного позитива, морали и мотивов других людей.
- При словах о нежелании жить, самоповреждении или опасности ролик не делается: спокойный экран и проверенные контакты помощи. Фильтр нельзя ослаблять.
- Тексты рассказов не пишутся на диск, в логи и метрики. Id пользователей в метриках — только хэш.
- Не оптимизируем удержание ценой самочувствия: ответ «стало тяжелее» ведёт к помощи, а не к уговорам.
